# ILMSPACE CodeLab

Синфхонаи онлайни C++ барои маркази омӯзишии **ilmspace.tj**. Устод дарс медиҳад ва масъала медиҳад. Шогирд дар браузер код менависад, санҷандаи воқеии C++17 онро месанҷад, ва устод дар экрани «Дарси зинда» мебинад, ки ба кӣ ва дар кадом қадам ёрӣ лозим аст.

- Ҳамаи матнҳо тоҷикӣ, вақт бо минтақаи Душанбе (UTC+5).
- 24 масъалаи аслӣ (6 мавзӯъ × 4) ва дарси омодаи «Шартҳо дар C++» бо 4 қадам.
- Мавзӯи торик (графит + фирӯзагӣ) ва равшан. Барои компютер, телефон (аз 360px) ва проектор.

## Оғози зуд (5 дақиқа)

Лозим аст: **Node.js 22+** ва **g++** (Linux; барои санҷандаи маҳаллӣ).

```bash
git clone https://github.com/manuchekhrbekhbudov-dot/ilmspace.tj.git
```

```bash
cd ilmspace.tj
```

```bash
npm install
```

> **Windows (PowerShell):** фармонҳоро як-як иҷро кунед — PowerShell 5 аломати `&&`-ро намефаҳмад. Барои санҷандаи маҳаллӣ g++ лозим аст: `winget install BrechtSanders.WinLibs.POSIX.UCRT`, баъд терминалро аз нав кушоед ва `g++ --version`-ро санҷед. Дар Windows барномаи шогирд бе ҷудокунӣ иҷро мешавад — барои санҷиш дар компютери худ кифоя, барои синф Judge0.

```bash
npm start
```

Баъд браузерро дар суроғаи **http://localhost:3000** кушоед. Ҳангоми бори аввал база (`data/codelab.db`) худкор сохта мешавад.

### Ҳисобҳои намоишӣ (маҳаллӣ)

| Нақш | Логин | Парол | Эзоҳ |
|---|---|---|---|
| Устод | `ustod` | `ilmspace` | Соҳиби ҳар ду гурӯҳ |
| Шогирд | `shogird` | `ilmspace` | Аъзои «C++ асосӣ — гурӯҳи 1» |
| Шогирди гурӯҳи дигар | `begona` | `ilmspace` | Аъзои «гурӯҳи 2». Барои санҷидани он ки дарсҳои гурӯҳи 1 ба ӯ дастрас нестанд |

**Гурӯҳи омода:** «C++ асосӣ — гурӯҳи 1». Курс 1 моҳ давом мекунад, ҳафтае 6 дарс (душанбе то шанбе, соати 14:00), ҳамагӣ 24 дарс аз **шанбе, 28.11.2026**. Санаи оғозро бо `COURSE_START=YYYY-MM-DD` пеш аз оғози аввал иваз кардан мумкин аст.

### Ҳисоби устоди худатон

Дар `.env` (ё дар Render: **Environment**) нависед ва серверро аз нав оғоз кунед:

```
TEACHER_LOGIN=manuchehr
TEACHER_PASSWORD=пароли-шумо-ҳадди-ақал-8-аломат
TEACHER_NAME=Манучеҳр
```

Ҳисоби намоишии `ustod` бо ҳамаи гурӯҳҳо ва дарси омода ба ҳисоби шумо табдил меёбад (`ustod` дигар кор намекунад). Барои иваз кардани парол — `TEACHER_PASSWORD`-ро иваз карда, серверро аз нав оғоз кунед.

### Роҳи дарси аввал (устод ва шогирд, 5 дақиқа)

1. **Устод** бо `ustod` ворид шавед. Дар «Дарсҳои омода» корти «Шартҳо дар C++» ҳаст. Гурӯҳи 1-ро интихоб карда, **«Ба гурӯҳ деҳ»**-ро пахш кунед. Дарс ба дарси навбатии гурӯҳ (28.11) гузошта мешавад ва саҳифаи «Дарси зинда» кушода мешавад.
2. **«Дарсро оғоз кун»**-ро пахш кунед.
3. Дар браузери дигар ё равзанаи махфӣ **шогирд** бо `shogird` ворид шавед. Дар саҳифаи аввал «● Дарс ҳозир меравад — Шартҳо дар C++» пайдо мешавад. **«Оғоз кун»**-ро пахш кунед.
4. Шогирд қадамҳоро иҷро мекунад:
   - **Пешгӯӣ кун:** ҷавобро нависед, баъд пешгӯӣ ва натиҷаи воқеиро паҳлуи ҳам бинед.
   - **Худат ҳал кун:** «Муқоисаи ду адад».
   - **Хаторо ёб:** барномаи хатодор.
   - **Санҷиши охири дарс:** саволи кӯтоҳ.
5. Устод дар ҷадвал ҳолати ҳар шогирдро бе refresh мебинад. Бо пахш ба хона кӯшиши охир, натиҷа, вақт ва код кушода мешавад. Бо пахш ба рақами сатр шарҳ гузоштан мумкин аст. Тугмаи **«Ҳолати проектор»** мисол, порчаи код ё натиҷаи овоздиҳиро бе номҳо ба экран мебарорад.
6. **«Дарсро анҷом деҳ»** ҳисоботро мекушояд. Он ба се савол ҷавоб медиҳад: кадом масъала мушкил буд, кӣ ҳанӯз ёрӣ мехоҳад, чиро такрор кардан лозим. Ҳар рақам ба рӯйхати кӯшишҳо мебарад. Аз ҳамин ҷо **«Вазифаи хонагӣ фирист»** низ мавҷуд аст.

### Шогирдони нав

Шогирд дар саҳифаи воридшавӣ **«Сабти ном (шогирд)»**-ро интихоб мекунад. Баъд яке аз ин ду роҳ:

- шогирд рамзи даъвати гурӯҳро ворид мекунад, ва устод дар саҳифаи гурӯҳ, ҷадвалчаи «Шогирдон», **«Қабул кун»**-ро пахш мекунад;
- ё устод логини шогирдро дар ҳамон ҷо менависад ва **«Илова кун»**-ро пахш мекунад.

Рамзи даъватро бо **«Рамзро иваз кун»** нав кардан мумкин аст. Рамзи кӯҳна баъд аз ин кор намекунад.

## Танзими санҷандаи C++

Код ҳамеша дар сервер иҷро мешавад. Калидҳо ва тестҳои пинҳонӣ ба браузер намераванд. Маҳдудиятҳои пешфарз: 2 с вақти CPU, 256 МБ хотира, 64 КБ баромад, 30 с барои компилятсия. Агар санҷанда танзим нашуда бошад, шогирд ва устод сабаб ва қадамҳои пайвасткуниро мебинанд. **Натиҷаи сохта ҳеҷ гоҳ нишон дода намешавад.**

### Варианти A — Judge0 (тавсия барои дарси воқеӣ)

Judge0 хидмати ҷудошудаи иҷрои код аст. Онро дар сервери алоҳидаи Linux бардоред. Аз саҳифаи release-ҳои github.com/judge0/judge0 версияи 1.13.x-ро гиред. Мувофиқи дастури онҳо: `judge0.conf`-ро бо паролҳо пур кунед, баъд `docker compose up -d db redis`, баъд `docker compose up -d`. Дар Ubuntu 22.04 ва навтар Judge0 cgroup v1 талаб мекунад, дастури онҳоро бинед. Сипас `.env`-ро созед:

```bash
cp .env.example .env
```

Дар `.env` чунин нависед:

```
JUDGE_DRIVER=judge0
JUDGE0_URL=http://<суроғаи-judge0>:2358
# агар AUTHN_TOKEN гузошта бошед:
JUDGE0_KEY=<калид>
```

Агар хидмати пулакии Judge0 (RapidAPI)-ро истифода баред:

```
JUDGE0_URL=https://judge0-ce.p.rapidapi.com
JUDGE0_KEY_HEADER=X-RapidAPI-Key
JUDGE0_RAPIDAPI_HOST=judge0-ce.p.rapidapi.com
```

Баъд серверро аз нав оғоз кунед (`npm start`). Дар консол сатри `Санҷандаи C++: judge0 → …` пайдо мешавад.

### Варианти B — санҷандаи маҳаллӣ (`JUDGE_DRIVER=local`, пешфарз)

Код бо g++ дар ҳамин сервер компилятсия ва иҷро мешавад. Дар Linux, агар сервер бо ҳуқуқи root кор кунад, ҳар барнома ҷудо иҷро мешавад:

- бе шабака (`unshare -n`);
- аз номи корбари бе ҳуқуқ `nobody` (`setpriv`);
- бо маҳдудияти хотира, вақти CPU ва ҳаҷми файл (`prlimit`).

Агар ин воситаҳо дастрас набошанд, сервер ва сарлавҳаи устод огоҳии **«Санҷандаи маҳаллӣ бе ҷудокунӣ»** нишон медиҳанд. Ин вариант барои санҷиш ва намоиш аст. Барои синфи воқеӣ бо шогирдони зиёд Judge0-ро истифода баред.

## Сохтор

```
server/
  index.js        — оғоз, .env
  app.js          — API, иҷозатҳо (ҳамааш дар backend тафтиш мешавад), навбати санҷиш, SSE
  db.js           — нақшаи SQLite (node:sqlite)
  judge.js        — драйверҳои Judge0 ва маҳаллӣ, маҳдудиятҳо, муқоисаи баромад
  explain.js      — шарҳи тоҷикии хатоҳои шинохташудаи g++ (рақами сатр аз паёми аслӣ)
  seed.js         — дарси «Шартҳо», гурӯҳи омода, ҳисобҳои намоишӣ, нақшаи 24 дарс
  seed/problems.js— 24 масъала + «Хаторо ёб»: шарт, мисолҳо, ишораҳо, ҳал, тестҳо бо тамғаҳо
web/src/          — интерфейс (Preact + htm, CodeMirror 6), бо esbuild ҷамъ мешавад
web/public/       — index.html, услубҳо, service worker (кушодан бе интернет)
scripts/          — build.js, verify-problems.js
tests/            — acceptance.cjs
```

**Маълумот алоҳида нигоҳ дошта мешавад:**

| Маълумот | Ҷадвал |
|---|---|
| Нусхаи машқӣ | `drafts` (+ `draft_conflicts`; ҳангоми ихтилоф ҳеҷ нусха гум намешавад) |
| Кӯшиши фиристодашуда | `submissions`: нусхаи дақиқи код ва версияи масъала |
| Натиҷаи баҳогузорӣ | `gradings` |
| Шарҳи устод | `comments`: ба кӯшиш ва сатр пайваст аст |

Нашри масъала версияи нав (`problem_versions`) месозад. Кӯшишҳои кӯҳна бо версияи худ фаҳмо мемонанд.

**Ҳолатҳои санҷиш:** дар навбат, иҷро, ҷавоби дуруст, ҷавоби нодуруст, хатои компилятсия, хатои вақти иҷро, гузаштан аз вақт/хотира/баромад ва нокомии хидмат (`SE`). `SE` ба пешрафт ва шумораи кӯшишҳо таъсир намерасонад. Пахши дукаратаи «Фирист» як кӯшиш месозад: тугма қулф мешавад ва сервер `client_token`-и такрориро ҳамчун ҳамон кӯшиш қабул мекунад.

## Базаи доимӣ (Supabase ё Neon, ройгон)

Дар нақшаи ройгони Render диск муваққатӣ аст. Агар `DATABASE_URL` гузошта шавад, барнома ҳар 10 сония нусхаи фишурдаи базаро ба Postgres (схемаи алоҳидаи `codelab`, ки тавассути Data API дастрас нест) мефиристад ва ҳангоми оғоз аз он барқарор мекунад.

**Supabase:**
1. Лоиҳа → тугмаи сабзи **Connect** → **Direct** → **Session pooler** → сатри `postgresql://…`-ро бо тугмаи нусхабардорӣ гиред (таҳрир лозим нест).
2. Ҳамон ҷо **Reset database password** — паролро нигоҳ доред.
3. Render → барнома → **Environment**:
   - `DATABASE_URL` = сатри нусхабардошта (бо `[YOUR-PASSWORD]` ҳамон тавр бимонад)
   - `DATABASE_PASSWORD` = пароли база
   → **Save, rebuild, and deploy**.

Санҷиш: `/api/health` → `"mode":"postgres"`. Агар `"invalid"` бошад, сабаб ба тоҷикӣ дар `lastError` навишта шудааст.

### Суръат дар Render

Render-и ройгон 0.1 протсессор ва 512 МБ хотира медиҳад. Санҷанда инро худаш муайян мекунад: санҷишҳо як ба як, хотираи барнома то 128 МБ ва `<bits/stdc++.h>` пешакӣ компилятсия мешавад (ҳангоми оғоз, дар пасманзар). Барои синфи 15–20 нафар нақшаи **Starter** (0.5 протсессор) тақрибан 5 маротиба тезтар аст. Ҳолат: `/api/judge/status` (`pch`, `parallel`, `isolation`).
